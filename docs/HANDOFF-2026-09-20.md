## 3. What the last seven rounds built

### 3.1 Adaptive icon text (the macOS behaviour)

**Problem Chris reported:** desktop icon labels were unreadable over light wallpaper.

**Fix:** `src/lib/contrast.ts` + `src/shell/useBackdropLuminance.ts` sample the wallpaper into
a luminance grid; `DesktopIcons.tsx` calls `labelStyle(x, y)` to choose `PAPER` (`#ffffff`) or
`INK` (`#050506`) per icon.

**Measured detail worth keeping:** `#0b0b0d` as ink **fails** WCAG AA at the crossover
luminance (ratio 4.44). `#050506` gives 4.52. Pure `#000000` gives 4.59. Do not "tidy" the ink
constant back toward `#0b0b0d`.

**Trap:** `labelStyle` must not read `surfaceRef.current` during render — that trips the React
Compiler `refs` ESLint rule, which is an **error** here, not a warning. It uses `useViewport()`
plus `topInset` instead.

### 3.2 The primary-button contrast bug (19 of 50 themes)

`globals.css` hardcoded `#04121c` text on a gradient accent. On 19 themes that failed AA.
`themes.ts` now emits `--on-accent` / `--on-accent2` computed per theme, and the button uses
`background: var(--accent); color: var(--on-accent)`. `scripts/check.mjs` now asserts it.

### 3.3 The widget creator — root cause and fix

**Chris's report:** "The widget creator IS NOT working at all."

**Root cause:** the old extractor required a *closed* markdown fence. It failed on (a) a prose
preamble before the code, (b) a reply truncated by the 4000-token cap so the closing fence
never arrived, and (c) models that emit a `<think>` block first.

**Fix:** `src/lib/extract-code.ts` handles closed fences (``` or ~~~, 3+ chars), **unclosed**
fences, `<think>` blocks (an unclosed one means no code, correctly), prose preamble via a
`MARKUP_START` regex, and bare JS via `CODE_START`. `explainNoCode(text)` produces a human
error instead of a silent blank.

`WidgetBuilder.tsx` now: `maxTokens: 8000`, `persona: false`, one automatic repair call when
extraction fails, then throws with `explainNoCode`. `IDE.tsx` re-exports the same extractor so
both paths share one implementation.

**Model selection:** `<ModelOverride id="widget" />` sits beside the Build button. Default is
the model selected in the top bar; the override picks a different one for that one generation.
`overrideOpts(v)` returns `{}` unless *both* provider and model are set — that is what makes
"inherit the top bar" the default.

### 3.4 For You — the AI suggests and builds

`src/apps/ForYou.tsx`. `src/kernel/activity.ts` records activity to `webaios.activity.v1`
(cap 300) and `gatherSignals()` merges: VFS files (skipping `/harness/`), user-created apps,
custom widgets, harness objectives, and chat history read from `localStorage["webaios.chat.v1"]`
(user turns only). The model proposes widgets and apps; one click adds a built-in widget,
generates a custom widget via `WIDGET_SYSTEM` + `extractCode`, or opens the app studio with a
seeded prompt. There is an offline fallback list and a rejected-suggestions list.

### 3.5 Pets you can create with a model

`src/lib/petgen.ts` holds `PET_PARTS` as the single runtime source of truth for what the
renderer can draw. `petPrompt()` quotes the user description as JSON data (prompt-injection
hygiene). `parsePetSpec()` validates **every** part against those lists — a model that invents
a part gets rejected rather than rendering a broken pet. `useCustomPets` persists to
`webaios.custompets.v1` (cap 60). `PetMaker()` lives in `Personalize.tsx`.

Pets can also steer the OS-level assistant: `settings.assistantSteering` is `"voice" | "pet"`.

### 3.6 Windows, desktops, icons, marquee

- **Same app on multiple desktops** — `resolveOpen` in `src/lib/window-open.ts`. The old
  `singleton` check ignored the workspace. The Dock had the same bug *plus* a `running` set
  that made the new "open elsewhere" marker unreachable.
- **Drag a maximized window down to restore it** — `Window.tsx` records
  `{x, y, ratio, offsetY}` in a `pendingRestore` ref on pointerdown while maximized; past 6px
  of movement it calls `wm.toggleMaximize` then `wm.move` so the cursor keeps its relative
  position on the title bar. `restoredW = win.restore?.w ?? 900` matches `toggleMaximize`'s
  own fallback — keep those two numbers equal.
- **Marquee selection** — widget cards are `pointer-events-auto` and were swallowing
  pointerdown before it reached the desktop surface (measured: no event arrived). The fix is a
  **window-level capture listener** plus `isBareDesktopPress`. An earlier attempt that made the
  widget body transparent was backed out; do not reintroduce it.

### 3.7 Agent Swarm

- Max tokens per agent now reaches **64,000**. The slider steps by 256, so the old default of
  `4000` was not on a step and the thumb reported 4,096 while the label said 4,000 —
  `DEFAULT_MAX_TOKENS` is now `4096`.
- The "64k" chip once rendered "63k" because `Math.round(64000/1024)` is 62.5. Chip labels are
  now explicit pairs, not computed.
- Agents can share one model or each carry their own role/personality/model, and there is an
  intelligent router model.
- `computeBid` abstains when an agent is missing any required skill, so agents must carry the
  formation's whole skill set — `profilesForFormation` builds that.
- Swarm success criteria read `run.answer` (every fixed check in `dod.ts` does); `run.transcript`
  is not what they read. Set `answer` to the report text.

   Earlier in the session `.glass` was arriving in the running app as `background` + `border`

   PostCSS pipeline contains both declarations inside the `@supports` block. Second, that

   backdropFilter: "blur(14px) saturate(1.5)"
   rule: @supports (backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px)) {

## 5. The environment hazard that will waste your afternoon

**The repo lives in an iCloud-synced folder. `node_modules` files get evicted to dataless
stubs.** When that happens `tsc`, `eslint`, and `next dev` hang for ten-plus minutes and then
sometimes succeed on a retry. It is not your code.

Detect it:

```bash
ls -lO node_modules/next/dist/bin/next
# "compressed,dataless" in the flags column means evicted
```

Warm it:

```bash
find node_modules -type f -print0 | xargs -0 -P16 cat > /dev/null
```

This is exactly what blocked the browser re-verification in §4.1. Warm `node_modules` **first**,
before you start a dev server, not after it stalls.

## 6. House rules for the code itself

### `src/lib` is pure

No `@/` imports. Relative imports carry **no** `.js` extension. No `window`, no DOM, no React,
no zustand. No `Date.now()`, `Math.random()`, or `performance.now()` — those are injected by the
caller so tests are deterministic.

### Adding a pure module

`tsconfig.test.json` has `rootDir: "src/lib"`, no `paths`, `module: nodenext`, no DOM lib. Tests
import from `../.test-build/<name>.js`. **A new module must be added to the `include` array
explicitly** or its tests will not compile.

### React Compiler lint rules are errors, not warnings

`set-state-in-effect`, `refs` (no `ref.current` during render), `preserve-manual-memoization`,
`purity`, `static-components`. The ESLint baseline is **zero errors**. Currently there is one
remaining warning elsewhere in the tree; the `win.w` unnecessary-dependency warning in
`Window.tsx` was fixed this session.

### `ask()` traps

- `role: "system"` inside `messages` is **silently dropped**. Use the `system` option.
- `persona` defaults to `true`. Pass `persona: false` for machine-shaped output.
- A budget stop **throws**. Catch it.
- Never double-count `res.costUsd`.

### `scripts/check.mjs` — the integrity gate

Asserts: icons resolve, app ids resolve, modules exist, persist keys are unique, app names are
unique, themes are legible (contrast + redmean accent distinctness + on-accent), no emoji, no
`console.log` outside template literals. It currently reports 32 app names, 50 themes, 139 files
scanned.

### `window.__aios` — the verification surface

The external control surface for browser verification: stores, apps, bus, ask, open/close,
snapshot, waitFor, harness, triggers, evals. Use it rather than clicking through the UI when you
need a check that can fail.

## 7. Bugs already found and fixed — do not "rediscover" these

- **Open Food Facts** blank-row filter compared against a `"(unnamed product)"` sentinel the
  code never produced (`str("")` returns `""`). Filter before naming.
- **REST Countries is deprecated.** Recorded-payload tests cannot detect provider deprecation;
  it was repointed at World Bank. All 42 services were live-probed.
- **`redirect: "error"`** killed every redirecting service. Replaced with per-hop SSRF-validated
  redirect following.
- **Live MCP tools inherited `requiresApproval: true`** from `annotationsFor`'s fail-closed
  default. With `approvals: "destructive"` and a deny-by-default approver, all ten would be
  refused. They now carry explicit annotations, and the test drives the real `runReAct`.
- **The feeds sanitizer test was wrong**, not the sanitizer. `<3` is literal text (no closing
  `>`) and survives correctly as escaped React text; escaped **tags** (`&lt;b&gt;`) are what get
  stripped.
- **I twice nearly reported `PinPicker` as broken** because my own probe used the selector
  `.glass.fixed` when the root is `fixed inset-0 z-[9700]`. Absence of evidence was not a
  finding. Check your selector before you file a bug.
